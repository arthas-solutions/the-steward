# Politique de sécurité

## Versions prises en charge

Seule la version la plus récente publiée de The Steward reçoit les correctifs de
sécurité. Les versions de développement et les anciens APK ne sont pas pris en
charge.

## Signaler une vulnérabilité

Ne publiez pas une vulnérabilité, une clé, une sauvegarde `.steward` ou des
données personnelles dans une issue publique.

Les signalements peuvent être envoyés à `contact@arthas.fr` avec l’objet
« Sécurité The Steward ». La fonction **Private vulnerability reporting** du
dépôt GitHub constitue le canal préféré lorsqu’elle est disponible.

Merci d’indiquer, sans joindre de données personnelles réelles :

- la version concernée ;
- le modèle d’appareil et la version Android ;
- les conditions de reproduction ;
- l’impact supposé ;
- une preuve de concept minimale si elle est nécessaire.

Une réception sera confirmée dans un délai raisonnable. Aucun délai de
correction ou programme de récompense n’est garanti.

## Périmètre particulièrement sensible

Les signalements concernant SQLCipher, la gestion de clé, les sauvegardes, le
verrou Control, les captures d’écran et les permissions Android seront traités
en priorité.
